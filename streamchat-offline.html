06 / 07

Local first.
Sync later.

Stream uses SQLite to persist cached chat data, then reconciles with the server when connectivity returns.

The provider can expose the client and cached conversation state earlier, without waiting for the full channel watch to complete.

Offline queueing does not guarantee delivery; pending, failed, and confirmed states are distinct.
