How it works

  1. One entry point. A single /ingest/source call branches on the payload: url, pdf_path, or text. YouTube URLs are detected by hostname and routed to the transcript fetcher.
  2. Text extraction. HTML is stripped to readable text, PDFs are read page by page, transcripts are cleaned of timing artefacts.
  3. Paragraph chunking. Splitting on blank lines keeps each chunk semantically whole — far better for extraction than fixed-width windows that cut sentences in half.
  4. Provenance. Every chunk becomes a turn with source_type and a source row, so each extracted memory can be traced back to the exact document and paragraph that produced it.
  5. Extraction then runs exactly as it does for conversation: the same entity, relationship and memory pipeline handles both.
