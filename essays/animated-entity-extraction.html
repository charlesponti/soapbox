How it works

  1. Chunking splits long input into batches of ~6 turns so each LLM call stays inside a reliable context window. Extraction that spans more text gets parallelised and merged.
  2. Extraction asks the model for a strict JSON schema: entities with a free-form type, relationships with source → relation → target, and memories with evidence quotes.
  3. Resolution normalises names (case, punctuation, aliases) and merges entities that resolve to the same node, summing mention counts instead of creating duplicates.
  4. Graph write persists nodes and edges in SQLite; recursive CTEs later answer "what is within N hops of X" without a graph database.

Free-form types mean the system never needs a hardcoded entity dictionary — a new domain introduces new types automatically.
