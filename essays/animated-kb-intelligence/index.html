How it works

  1. Claim verification compares new statements against existing ones that share a slot. Same slot + different value + both user-stated means a genuine conflict rather than an addition.
  2. Contradiction detection does not silently overwrite. The newer claim supersedes the older, and the old row is kept with valid_to set — so the history of belief is auditable.
  3. Pattern surfacing counts co-occurrence across unrelated memories and entities. When a bridge entity appears in several otherwise unconnected topics, it is promoted as a pattern.
  4. Linting runs five passive checks — low confidence, missing slots, duplicates, orphaned entities, deprecated pages — and reports a health score. It never mutates; it tells you where to look.

The distinction that matters: linting observes, resolution acts, and both keep the supersession trail intact.
