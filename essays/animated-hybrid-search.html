How Hybrid Search Works

The animation above shows how four retrieval strategies combine:

  1. FTS5: SQLite full-text search finds memories containing query terms ("CSS", "framework", "use").
  2. Exact keyword: Substring matching catches memories that FTS5 might miss due to tokenization.
  3. Vector search: sqlite-vec cosine similarity finds semantically related memories even when keywords don't match. "CSS framework" matches "Tailwind CSS" via embedding similarity.
  4. Graph traversal: Entity lookup finds memories connected to entities mentioned in the query.

All candidate IDs are unioned, then scored by confidence × importance × recency, and the top results are returned with an abstention check (if max score < 0.15, return empty).
